How it scores

      
Three tiers, and one rule above them.

      

        
Code
Counted and checked against the list. Three named wines, the right price, no invented vintage.

        
Rubric
A person or a model judge. Did it claim to book? Did it invent a bottle? Name the judge when you report.

        
Sommelier
Taste and reading the guest. Never automated, and shown as pending until a person scores it.

      

      
A wrong price fails the question, whatever it was testing. There is no overall score until every question has one, because a partial number gets quoted as the whole one.

      
The checker is built to miss an error before it invents one. It will not catch a price written out in words, and it cannot tell whether a pairing is any good.
