# The Aster Room Test

Forty questions a guest asks a restaurant's AI about wine. Paste your agent's replies and this page checks every price against the list, scores what code can score, and shows what only a sommelier can.

It runs in your browser. Nothing you paste leaves the page.

- Data: https://huggingface.co/datasets/woodywu-sommelier/hospitality-agent-evals
- Code and tests: https://github.com/woodywu-sommelier/hospitality-agent-evals
- A test set on your own venue and data: https://woodywusommelier.com/consulting/ai-teams/

The Aster Room is fictional. Every producer, price and policy was invented for this test.

Built by Woody Wu, sommelier, hospitality operator and AI builder.
